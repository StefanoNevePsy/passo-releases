# Passo — download

Applicazioni compilate per macOS e Android. Il codice sorgente rimane in una repository privata.

Scarica l’ultima versione dalla [pagina Release](https://github.com/StefanoNevePsy/passo-releases/releases/latest):

- **Passo-Mac.zip**: estrai e sposta Passo.app in Applicazioni.
- **Passo-Android.apk**: installa come aggiornamento, senza disinstallare la versione precedente.

Dalla versione 0.6 Passo include controllo aggiornamenti, download verificato e avvio dell’installazione nelle Impostazioni. Il sistema può richiedere conferma. Le versioni precedenti richiedono una prima installazione manuale della 0.6 o successiva.

Android mantiene la stessa firma di rilascio. La versione Mac usa firma locale ad hoc e non è notarizzata da Apple.

Questo canale contiene soltanto pacchetti, checksum e manifest di aggiornamento: nessun calendario o piano personale.
